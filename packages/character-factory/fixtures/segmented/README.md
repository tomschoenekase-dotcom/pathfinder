# Deterministic fixture segmentation

These SVG layers are deterministic extractions and simplifications of the pinned OpenMoji 16.0.0
fixtures in `../source`. They retain the source attribution and CC BY-SA 4.0 license recorded in
`../ATTRIBUTION.md`; they are modified test assets and remain licensed CC BY-SA 4.0.

- Owl: body/head, separately moving wing, and face.
- Astronaut: torso and separately moving helmet/head. The source does not separate arms, so this rig
  makes no independent-arm claim.
- Morph: deforming body and separately moving face.

The layers prove meaningful family articulation in the actual React renderer. They are architecture
fixtures, not production art or final Tochi candidates.
