# App WebView integration

The current Distribution RC-1 app contract is in [Visitor distribution](distribution/README.md) and the [app WebView host guide](distribution/app-webview-host-guide.md). Use `/app/<slug>` as the canonical URL; `/embed/<slug>?chrome=hidden` remains a compatibility alias.

The guide covers WKWebView, Android WebView, React Native, Flutter, external links, permissions, text scaling, keyboard/safe areas, and device proof. RC-1 is local/CI review work and is not a staging or production rollout.
