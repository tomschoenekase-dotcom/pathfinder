## Baseline discovered before implementation

- No Stripe SDK or Stripe billing domain exists.
- `Tenant.planTier` and manually edited `Tenant.nextPaymentDue` are the only billing-adjacent customer fields.
- Product entitlements already resolve independently through plan capabilities and time-bounded tenant/venue overrides.
- Tenant isolation, strict audit persistence, operational-event deduplication, background workers, public-surface inventory, client-bundle secret scanning, and environment validation are established repository patterns and are mandatory integration points.
